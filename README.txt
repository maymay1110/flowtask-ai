FLOWTASK AI — SITE DO PROJETO

COMO ABRIR NO VS CODE
1. Extraia o arquivo ZIP para uma pasta do computador.
2. Abra o Visual Studio Code.
3. Clique em File/Arquivo > Open Folder/Abrir Pasta e selecione a pasta "flowtask-ai-site".
4. Abra o arquivo index.html.
5. Para visualizar o site, clique duas vezes no index.html no Explorador de Arquivos ou use a extensão "Live Server" no VS Code e clique em "Go Live".

ARQUIVOS
- index.html: conteúdo e estrutura do site
- style.css: cores, layout e responsividade
- script.js: menu para celular e ano automático

OBSERVAÇÕES
- O site é uma apresentação visual de um projeto conceitual para fins educacionais.
- A plataforma FlowTask AI não é apresentada como um produto já funcional.
- Os textos, e-mail ilustrativo e elementos visuais podem ser personalizados.
- As fontes são carregadas do Google Fonts quando há conexão com a internet; o site continua funcionando sem elas.
